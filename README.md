## 📦 Installation

### Prérequis
Avant de commencer, tu dois avoir **Node.js** installé sur ton PC.

👉 [Télécharge Node.js ici](https://nodejs.org/en/download) (prends la version LTS, c'est la plus stable)

### Étapes d'installation

1. **Clone le projet** (ou télécharge-le)
   ```bash
   git clone https://github.com/the-dev-loic/Gestion_de_lordre_ma_metier.git
   cd Gestion_de_lordre_ma_metier
   ```

2. **Installe les dépendances**
   ```bash
   npm install
   ```

3. **Installe nodemon** (pour que le serveur redémarre automatiquement)
   ```bash
   npm install -g nodemon
   ```

4. **Lance le serveur** 🚀
   ```bash
   nodemon index.js
   ```

5. **Ouvre ton navigateur** et va sur :
   ```
   http://127.0.0.1:28015
   ```

Et voilà ! Ton site tourne en local ! 🎉
